# Free asset and addon policy
Use only no-account, no-payment downloads with verified commercial use and redistribution rights. Prefer CC0 assets and MIT/BSD/Apache software. Preserve license files and attribution. Blender GPL tools stay in authoring environment; review output licenses separately. Never install unreviewed executables or floating main branches. Pin versions and SHA256 hashes. Test Godot 4.4.1 Compatibility and Blender headless before integration. Keep Android 14 ARM64 offline runtime. Candidates (not installed): Kenney audio and UI, Quaternius animations, ambientCG and Poly Haven textures, individual Godot Shaders with verified licenses, Blender Rigify and LoopTools. Record source, version, license, checksum and integration status per asset. No paid services, account requirements or telemetry.
