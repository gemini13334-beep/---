# Free asset and addon policy
Use only no-account, no-payment downloads with verified commercial use and redistribution rights. Prefer CC0 assets and MIT/BSD/Apache software. Preserve license files and attribution. Blender GPL tools stay in authoring environment; review output licenses separately. Never install unreviewed executables or floating main branches. Pin versions and SHA256 hashes. Test Godot 4.4.1 Compatibility and Blender headless before integration. Keep Android 14 ARM64 offline runtime. The adopted packages, attribution, sources and hashes are recorded in ASSET_MANIFEST.md and assets/vendor/SHA256SUMS. Review any additional assets individually before importing them. No paid services, account requirements or telemetry.
