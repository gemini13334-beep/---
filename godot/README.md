# ОТПУСК / TACTICAL — Godot 4

Нативный проект для Android. Старые HTML/Babylon.js файлы в корне репозитория не удалены.

## Сюжет
Герой (сам игрок) пытается получить отпуск до Нового года. Враги — военные зомби-клерки. База — коморка с личным делом и прокачкой. Финальный босс Денис — толстый, вредный начальник с мерзкой ухмылкой, которого нужно победить умом.

## Состояние переноса
Первый нативный каркас: 3D-арена, персонаж, враги, мобильное управление, автоматический огонь, кампании, бесконечный режим, меню и сохранение. Геометрия и модели временные; Babylon.js ресурсы и художественные ассеты ещё не полностью перенесены.

Открыть папку `godot/` как проект Godot 4.3+. Рендерер Compatibility для Android.
