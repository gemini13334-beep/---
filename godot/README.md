# ОСОБЫЙ ОТДЕЛ

Игра от первого лица для Android на Godot 4.5.1. Герой пытается получить подпись на рапорте об отпуске до Нового года. Кампания состоит из пяти этапов. Также доступен бесконечный режим.

Военные зомби-клерки охраняют проходную, а в последней операции герой добивается подписи начальника Дениса. Базой служит коморка с личным делом.

В лобби нажмите **Играть**, выберите этап кампании или бесконечный режим и нажмите **Начать**. Завершённые этапы можно проходить повторно. Инвентарь, снаряжение, кейсы, профиль и настройки открываются из верхней панели.

Во второй операции бой переносится в зал канцелярии. Подойдите к трём жёлтым папкам на стойках и победите 18 клерков, чтобы открыть архив. Ромбы на радаре показывают текущие цели. В архиве личное дело лежит у третьего фонда. В штабе нужно восстановить два узла связи. В финале заберите рапорт в приёмной и подойдите к столу начальника за подписью.

На телефоне двигайтесь левым джойстиком, для обзора ведите пальцем по свободной правой части экрана. На компьютере используйте WASD и мышь. Для автострельбы наведите центр прицела на видимую часть противника. При отключённой автострельбе стреляйте кнопкой «Огонь», левой кнопкой мыши или пробелом. Q переключает снаряжение, R перезаряжает, Esc возвращает в лобби.

Откройте эту папку в Godot 4.5.1. Для Android используется рендерер Compatibility. Ранние браузерные прототипы находятся в корне репозитория.

## Подпись Android

Установочный пакет использует имя `org.otpusk.tactical.game`. Он устанавливается рядом со старыми тестовыми сборками `org.otpusk.tactical`, для которых CI генерировал новый ключ при каждом экспорте. Android хранит данные этих приложений отдельно.

Workflow собирает ARMv7, ARM64 и x86-64 в одном APK. Код версии берётся из номера сборки. Для автоматической публикации в GitHub Actions задаются секреты `OTPUSK_KEYSTORE_BASE64` (PKCS12 с псевдонимом `otpusk`) и `OTPUSK_KEYSTORE_PASSWORD`. Отпечаток публичного сертификата закреплён в workflow.

При работе с офлайн-ключом скачайте артефакт `android-export`, подпишите APK с помощью `apksigner` и приложите его к черновику релиза `android-build-N`, где N — номер сборки. Укажите полный SHA собранного коммита как target черновика. Пуш тега `android-verify-N` на этот коммит запускает установку на эмуляторе и публикацию проверенного файла.
