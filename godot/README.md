# ОТПУСК / TACTICAL

Игра от первого лица для Android на Godot 4.3. Герой пытается получить подпись на рапорте об отпуске до Нового года. Кампания состоит из пяти этапов. Также доступен бесконечный режим.

Военные зомби-клерки охраняют проходную, а в последней операции герой добивается подписи начальника Дениса. Базой служит коморка с личным делом.

В лобби нажмите **Играть**, выберите этап кампании или бесконечный режим и нажмите **Начать**. Завершённые этапы можно проходить повторно. Инвентарь, снаряжение, кейсы, профиль и настройки открываются из верхней панели.

На телефоне двигайтесь левым джойстиком, для обзора ведите пальцем по свободной правой части экрана. На компьютере используйте WASD и мышь. Держите противника вблизи прицела. При отключённой автострельбе стреляйте кнопкой «Огонь», левой кнопкой мыши или пробелом. Q переключает снаряжение, R перезаряжает, Esc возвращает в лобби.

Откройте эту папку в Godot 4.3. Для Android используется рендерер Compatibility. Ранние браузерные прототипы находятся в корне репозитория.
